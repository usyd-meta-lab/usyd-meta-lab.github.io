Before you start

Two judgements per trial

First decide which side had more dots. Then rate your confidence in that decision from 1 to 4. Confidence means how likely you think it is that you were right, so use the full range. If you were guessing, say 1. If you are sure, say 4.

How it works

  • The dots flash up briefly, so look at the centre and take it in as a whole.
  • The task adjusts itself to be hard for you, so expect to get some wrong. That is the point, because we need errors to measure metacognition.
  • You get feedback during practice only. There is no feedback in the main block.
  • On a computer you can use the left and right arrow keys, then the number keys 1 to 4.

Why your own numbers are rough

Metacognitive sensitivity needs a lot of trials to pin down. With a few dozen trials your personal estimate bounces around a great deal, which is why the class pool on the projector is far more trustworthy than anything here.
